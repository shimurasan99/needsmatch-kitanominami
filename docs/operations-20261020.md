# 運営機能追加（2026-10-20）

## 操作

- `/entry`：HP参加申込。公開されている確定月例会のうち、申込期限内かつ開始前の日程のみ。月例会管理の開催日・会場を参照。
- `/admin/operations` → 「参加申込受付」：申込内容を確認し、本人・参加区分と月例会を選んで「確認して参加者名簿へ反映」。既存の原子的な出欠保存を使用。テーブル配置はテーブル割り画面で追加。
- `/admin/routines`：対象月を選び、担当者・期限・完了チェック・メモを編集して保存。別の月と履歴を分離。同時編集で古い内容から上書きしない。
- `/admin/member-resources`：会員番号の数値昇順を既定表示（ユーザー指定。入会順の参考であり、入会日を推測しない）。同じ番号の人を統合しない。確認済み入会月順への切替、CSV保存、入会月・根拠の編集が可能。
- 同画面の「1on1シートを保管・確認」：会員ごとにPDF/JPEG/PNG/WebP、3MB以下を保存。過去版は残る。従来のURLは別途参照できるが、外部の実ファイルは自動移行していない。

## 保存と権限

- 既存の Supabase `shared_site_state` を利用。新しいSQLマイグレーションは不要。
- ルーティン `admin-record:routines-YYYY-MM`、入会情報 `admin-record:joining`。運営専用GET/PUT、If-Matchによる楽観ロック。
- HP申込は `admin-form:<HMAC ID>`、既存のGoogle回答と同じ非公開受信箱へ保存。連絡先や詳細は公開参加者データへコピーしない。
- HPフォームは署名付き2時間トークン・同一送信の重複防止・ハニーポット・IPハッシュ単位の永続CAS回数制限（1時間10件）を使用。入力を控えずに長時間放置しないこと。
- 申込の再送で、運営が反映済みの記録を上書きしない。開催日が変更された場合は受付を止めて再確認を促す。
- 1on1は `admin-one-on-one` 非公開Storageバケットを初回アップロード時に作成。service_roleだけが操作。公開設定のバケットには保存・配信しない。ダウンロードは運営認証後に60秒の署名URLを発行し、添付ファイルとして配信。
- バケット名、オブジェクト名から個人名を露出させない。元ファイル名は保存日時・UUIDへ置換。
- メール送信サービスは追加していない。画面に受付番号を表示し、自動返信メールが送られないことを明示。運営は受信箱で確認する。
- 旧Googleフォーム連携は削除せず、折りたたみで残す。HP申込にGoogle承認は不要。
