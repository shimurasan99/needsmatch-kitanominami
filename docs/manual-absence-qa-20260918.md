# 急な欠席への対応・検証記録（2026-09-18）

## 動作

- 各席の「欠席にする」→確認ダイアログ→本人の出欠保存が確認できた場合だけ席を除去。
- 他の席順、テーブル名、空テーブルは維持。出欠保存と配置保存・公開は別操作として画面に明記。
- 会員は会員番号＋氏名の一意照合、個別出欠の更新版でCAS保存。ゲストは氏名＋表示会社の一意照合、最新ゲスト一覧のCAS保存。
- テーブルだけに登録されたゲストは配置のみ除去し、その旨を表示。曖昧な照合、競合、通信エラーは配置を保持。
- 参加者管理でもゲストの参加／欠席を選択可能。過去のstatus未指定ゲストは参加扱いを維持。欠席を集計・CSV・自動生成に反映。
- 007で空席のみのテーブル公開に対応。0件のテーブル配列や不正な配列は引き続き拒否し、公開版・保存版の競合検知とサーバー専用権限を維持。
